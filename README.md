# Grungy

Standalone web version of Grungy.

## GitHub Pages

Use [`index.html`](index.html) at the repo root as the Pages entrypoint.
The repo also includes `.nojekyll` so GitHub Pages serves the static files without Jekyll processing.

## Notes

- The app uses relative paths for CSS, JS, fonts, and images.
- Cordova-specific features are still present in the code, but the page now has a browser fallback so it can run on GitHub Pages too.
