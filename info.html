Grungy

Photo filter and effect tool — grungy textures and CamanJS-powered adjustments.

Language JavaScript
GitHub adrian3/grungy  (Private)
GitHub Pages https://adrian3.github.io/grungy/
What it does
  • Applies grungy, distressed photo effects using layered canvas filters
  • Effects include vignette, burn, scratches, and border overlays
  • Color and black-and-white modes with a configurable default
  • Load photos from camera, library, or file picker
  • Originally a Cordova mobile app — now runs as a standalone web page
How to use

Open the app and tap the image to load a photo. Swipe through the preset filters to find a look you like. Use the settings panel to change the photo source or default color mode.

Built with
CamanJS Canvas image processing — applies all filters and adjustments
jQTouch Mobile UI framework — handles touch navigation and transitions
